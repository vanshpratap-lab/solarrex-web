# Hosting & Deployment Layer

This directory represents the **Hosting & Deployment** layer of the Solar Rex stack.

## Architecture

- **Primary Cloud Host**: Vercel (Edge-cached hosting platform)
- **Routing Protocol**: `vercel.json` for redirection paths, rewrite structures, custom headers, and security rules.
- **Build Output**: Static HTML, CSS, JS bundles compiled by Vite.
